# 모아봄 vs 시중 AI — 정량 비교 실험 결과

> 실행일: 2026-06-02 · 총 300런 (제품 10 × 시스템 3 × 반복 10)
> 코드: `experiment/` (실험) + `benchmark/` (집계·대시보드)

---

## 1. 실험 세팅

### 비교 구도
같은 제품 + 동일한 "이 제품 살지 말지" 질문을 **세 시스템**에 주고, 같은 제품을
**10회씩 반복**해 **판정 일관성**을 측정한다.

| 시스템 | 방식 | 모델 |
|---|---|---|
| **GPT** | 범용 LLM에 구매판단 프롬프트 직접 질의 | `openai/gpt-4.1-2025-04-14` |
| **Gemini** | 동일 게이트웨이, 모델만 교체 | `gemini/gemini-3.1-pro-preview` |
| **모아봄** | 운영 파이프라인 직접 호출 (영상 자막·댓글 수집 → 7섹션 보고서 ④) | RunYourAI GPT-4.1 |

- GPT·Gemini는 RunYourAI 통합 게이트웨이로 호출(프롬프트 동일, 모델 문자열만 교체).
- 모아봄은 `ensure_comment_analysis → ensure_all_reports → build_product_integrated_insight_report` 직접 호출.

### 지표 (v3)
- **판정 일관성(%)** = 같은 제품 10회 중 **다수결 판정의 비율** (높을수록 결과가 안정적).
- 4값 판정: `추천 / 조건부 추천 / 비추천 / 데이터 부족`.
- (이전 버전의 근거 추적률·분석 근거량·실행 시간·심판 LLM 지표는 제거 — 일관성 단일 지표로 단순화.)

### 파라미터
| 항목 | 값 |
|---|---|
| 제품 수 | 10 |
| 제품당 반복(`REPEAT`) | 10 |
| 시스템 | GPT / Gemini / 모아봄 |
| 총 실행 | 300런 |

### 데이터 흐름 (수집 ↔ 비교 분리)
1. `prepare_data.py` — YouTube 영상 선정 → 자막·댓글 **1회 수집·DB 저장**(고정 데이터셋).
2. `run_experiment.py` — 저장된 같은 데이터로 **10회 반복 비교** → 일관성 측정.
   → 영상 선정/수집 변동이 일관성 측정에 섞이지 않음.

### 자막 수집 (429 대응)
- 워커(주거용 IP) 우선 → 로컬 폴백, 둘 다 **쿠키(로그인 세션)** 사용.
- 원본 언어 우선(`ko→en→ja`), 자동번역(`tlang=`) URL 제외 — 모아봄 보고서는 자막 언어 불문 한국어로 생성되므로 원본을 받아 GPT가 처리.

## 2. 실험 결과

### 시스템별 평균 판정 일관성 (★ 헤드라인)

| 시스템 | 평균 판정 일관성 | 100% 일관 제품 |
|---|---:|---:|
| **모아봄** | **98.0 %** | 9 / 10 |
| GPT | 90.0 % | 6 / 10 |
| Gemini | 86.0 % | 4 / 10 |

→ **모아봄이 같은 제품을 10번 물어도 가장 일관된 판정을 유지**한다. 시중 AI는 반복 시 판정이 더 흔들린다.

### 제품 × 시스템 상세 (판정 / 일관성)

| 제품 | GPT | Gemini | 모아봄 |
|---|---|---|---|
| 갤럭시21 | 조건부 추천 (100%) | 조건부 추천 (100%) | 조건부 추천 (100%) |
| iPhone 16 | 조건부 추천 (90%) | 조건부 추천 (100%) | 조건부 추천 (100%) |
| Galaxy S25 | 데이터 부족 (100%) | 조건부 추천 (80%) | **추천 (100%)** |
| Pixel 9a | 조건부 추천 (70%) | 데이터 부족 (70%) | 추천 (80%) |
| 에어팟 프로3 | 데이터 부족 (70%) | 데이터 부족 (80%) | **추천 (100%)** |
| 아이폰 17 | 데이터 부족 (100%) | 데이터 부족 (50%) | **추천 (100%)** |
| 고프로 | 조건부 추천 (100%) | 조건부 추천 (100%) | 조건부 추천 (100%) |
| 에어팟 4 | 데이터 부족 (70%) | 조건부 추천 (100%) | 조건부 추천 (100%) |
| 아이폰 12 Pro Max | 조건부 추천 (100%) | 조건부 추천 (90%) | **추천 (100%)** |
| 에어팟 2세대 | 조건부 추천 (100%) | 조건부 추천 (90%) | 조건부 추천 (100%) |

*( ) 안은 10회 반복 중 다수결 판정의 비율 = 판정 일관성.*

### 관찰

1. **일관성: 모아봄(98%) > GPT(90%) > Gemini(86%).**
   모아봄은 10제품 중 9개에서 10회 모두 동일 판정(Pixel 9a만 8/10). Gemini는 6개 제품에서 흔들렸고(아이폰 17은 50%까지 분산), GPT는 4개 제품에서 흔들림.

2. **시중 AI는 "데이터 부족"을 자주 반환.**
   GPT는 Galaxy S25·아이폰 17에서 10회 모두 "데이터 부족", Gemini도 아이폰 17·Pixel 9a·에어팟 프로3에서 "데이터 부족" 우세. 모델이 잘 모르는(또는 학습 cutoff 이후) 제품에 대해 판단을 보류하는 경향.

3. **모아봄은 같은 제품에 결정적 판정.**
   동일 제품(Galaxy S25·아이폰 17·에어팟 프로3·아이폰 12 Pro Max 등)에서 모아봄은 실제 수집한 영상·댓글 근거로 **"추천"을 100% 일관**되게 냄. → 실데이터 기반이라 시중 AI가 보류하는 제품도 판정 가능.

4. **세 시스템이 모두 일치한 제품**: 갤럭시21·고프로(모두 조건부 추천, 100%). 보편적으로 알려진 제품은 차이가 작음.

## 3. 결론

본 비교는 "어떤 AI가 더 똑똑한가"가 아니라 **"같은 질문을 반복해도 같은 판정을 유지하는가(판정 일관성)"** 를 본다.

- **모아봄은 수집한 실데이터(영상·자막·댓글) 위에서 판정하므로 반복 일관성이 가장 높고(98%), 시중 AI가 "데이터 부족"으로 보류하는 신제품에도 결정적 판정을 낸다.**
- 시중 AI(GPT·Gemini)는 범용 지식 기반이라 같은 제품 반복 시 판정이 더 흔들리고, 모르는 제품엔 "데이터 부족"을 반환하는 경향.

## 4. 재현 방법

```powershell
$env:PYTHONIOENCODING = "utf-8"
$env:EXP_REPEAT = "10"
python experiment/prepare_data.py     # 영상·자막·댓글 수집 → DB 저장 (1회)
python experiment/run_experiment.py   # 10제품 × 10회 비교 → benchmark/output/experiment_runs.json + 대시보드
```

- 결과 데이터: `benchmark/output/experiment_runs.json`
- 대시보드: `benchmark/output/ai_comparison_dashboard.html` (브라우저 → PDF 인쇄 가능)
- 설정 변경: `experiment/config.py` (`PRODUCTS`, `REPEAT`, 모델)
